Root-cause hypothesis

suspect __netconfig_wifi_enable_technology calls netconfig_invoke_dbus_method with a synchronous g_dbus_proxy_call_sync and no timeout argument. When ConnMan is still racing to recognize the freshly-loaded driver, that sync call blocks the main loop for ~30 s (GIO's default).

Evidence trail

1 · entry __netconfig_wifi_airplane_mode fires when airplane mode flips off (degree 3, community 0). Calls __netconfig_wifi_try_to_load_driver.
2 · interlock checks pass Tethering off, wifi-direct off → control reaches __netconfig_wifi_load_driver.
3 · race condition Kernel module loads (insmod returns) but wlan0 hasn't been enumerated by ConnMan yet.
4 · the hang __netconfig_wifi_enable_technology issues a sync D-Bus call via netconfig_invoke_dbus_method. ConnMan can't reply → main loop blocks.
5 · timeout cascade Outer timer fires __netconfig_wifi_try_to_remove_driver → driver yanked → next toggle has to redo everything.

Why the graph caught this fast

One query showed three of the four functions in the log are in community 0 (WiFi driver lifecycle, 27 nodes) and that netconfig_invoke_dbus_method is the only path out to ConnMan (degree 9) — so any hang involving ConnMan necessarily funnels through it. That's the choke point to patch.

Suggested fix area

option A — narrow Patch netconfig_invoke_dbus_method to use g_dbus_proxy_call (async) with a 3 s timeout + completion callback. blast radius: 7 callers
option B — surgical Add a "wait for wlan0 to appear on ConnMan" pre-step in __netconfig_wifi_try_to_load_driver before invoking enable_technology. blast radius: 1 caller
option C — defensive Wrap the sync call but cap the GIO default timeout via g_dbus_proxy_set_default_timeout(proxy, 3000) during init. blast radius: 0 (init-time only)

What still needs verification

The edge __netconfig_wifi_enable_technology → netconfig_invoke_dbus_method is INFERRED (heuristic), not AST-confirmed. Verify by grep before patching. Likewise the airplane-mode → load-driver edge is EXTRACTED ✓ — that one's safe to trust.
